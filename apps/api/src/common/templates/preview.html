📧 Email Templates Preview

Preview of all Time2Ship transactional email templates

Note: To preview actual rendered emails, you need to generate them from the EmailService. This is a static preview file. Run the templates through the service to see the real output.

1. Welcome Email

Sent when a user successfully registers for an account

Key Features:
  • Welcoming message with emoji
  • User account details in info box
  • Getting started checklist
  • Call-to-action button to dashboard
  • Support contact information

Triggers:
  • User completes registration
  • Called from auth.service.ts after user creation

2. Password Reset Email

Sent when a user requests a password reset

Key Features:
  • Clear reset button with secure link
  • Expiration notice (1 hour)
  • Security warning if not requested
  • Alternative plain text link in code block
  • Professional security notice in info box

Security Considerations:
  • Token expires in 1 hour
  • One-time use token
  • Clear warning for users who didn't request reset

3. Email Verification Email

Sent when a user needs to verify their email address

Key Features:
  • Verification button with secure link
  • Expiration notice (24 hours)
  • Explanation of why verification is needed
  • Alternative plain text link in code block
  • Ignore notice for unsolicited emails

Usage:
  • Optional email verification flow
  • Can be integrated into registration or account settings
  • Token expires in 24 hours

Email Template Components

All templates use modular components from email-layout.ts:

Component Purpose
createEmailLayout() Base wrapper with responsive design
emailHeading() Styled H1 heading
emailParagraph() Styled paragraph
emailButton() Call-to-action button
emailInfoBox() Highlighted info box
emailCodeBlock() Monospace code/token display
emailSignature() Consistent sign-off
emailDivider() Horizontal divider

How to Preview Actual Emails

To see the actual rendered emails:

  1. Development Mode: Set up email credentials in .env and send a test email
  2. Log Output: Check console logs in test mode to see email subjects
  3. Email Testing Service: Use services like Mailtrap or Ethereal Email for development testing
  4. Unit Tests: Run npm test -- email.service.test.ts to verify templates generate correctly

Configuration Required

Set these environment variables in apps/api/.env:

EMAIL_HOST=smtp.gmail.com
EMAIL_PORT=587
EMAIL_SECURE=false
EMAIL_USER=your-email@gmail.com
EMAIL_PASSWORD=your-app-password
EMAIL_FROM=noreply@time2ship.com
EMAIL_FROM_NAME=Time2Ship
CLIENT_URL=http://localhost:3000
