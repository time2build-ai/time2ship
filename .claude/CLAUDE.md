# Time2Ship Boilerplate

This is a monorepo containing multiple applications. Each app has its own specific guidelines and requirements.

## App-Specific Instructions

Before working on any application, you MUST load and follow its specific CLAUDE.md file:

- **Client App**: [apps/client/.claude/CLAUDE.md](apps/client/.claude/CLAUDE.md) - React/Next.js frontend guidelines, architecture, and skills
- **API App**: [apps/api/.claude/CLAUDE.md](apps/api/.claude/CLAUDE.md) - Express/TypeScript API guidelines, feature-based architecture, patterns and skills
- **Other Apps**: Check for `.claude/CLAUDE.md` in each app directory

Always load the relevant app's CLAUDE.md file before starting work on that application.
